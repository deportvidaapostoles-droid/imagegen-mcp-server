ImageGen MCP Server

Remote MCP server for AI image generation and editing (OpenAI-compatible and Google Gemini providers), running as Vercel serverless functions.

Endpoints

  • POST /mcp — MCP endpoint (Streamable HTTP transport, stateless)
  • GET /health — health check (alias of /api/health)
  • POST /api/upload — upload an image and get a URL for edit_image (drag-and-drop page)

Access

This deployment may require OAuth: unauthenticated requests are answered with 401 and a WWW-Authenticate header pointing at /.well-known/oauth-protected-resource/mcp, which modern MCP clients follow automatically to log you in. Check /health to see whether authentication is enabled.

Connect an MCP client

{
  "mcpServers": {
    "imagegen": {
      "type": "http",
      "url": "https://<your-deployment>.vercel.app/mcp"
    }
  }
}

Tools

  • generate_image — text to image
  • edit_image — edit one or more images with a prompt
  • submit_task / get_task — async task API
  • upload_image — store an image and get a URL (when a Blob store is connected)
This page is the only static asset of the deployment; all functionality is served by the serverless functions above.
